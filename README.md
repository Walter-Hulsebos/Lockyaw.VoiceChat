# Install Lockyaw Voice Chat in Unity

> Requires **Unity 6 (6000.0 or newer)** and **Git** installed on your computer.

1. Open your Unity project.
2. Go to **Window → Package Management → Package Manager**.
3. Click the **+** button in the top-left corner.
4. Select **Install package from Git URL…**
5. Paste this URL:

```text
https://github.com/Walter-Hulsebos/Lockyaw.VoiceChat.git#stable
```

6. Click **Install**.
7. Wait for Unity to download and import the package.

The package will appear as **Lockyaw Voice Chat** in the Package Manager.
